# 雅思补充：2026 年 9–12 月口语新题 + 写作模板

- 网址：https://ielts.xhr0417.cn （自有服务器）
- 镜像：https://xhr0417.github.io/ielts-supplement/ （GitHub Pages，push 后自动更新）
- 离线：`site/index.html` 是单个文件，双击用浏览器打开就能用，不需要联网

资料更新到 2026-10-13。

## 网页里有什么

| 栏目 | 内容 |
|---|---|
| Part 1 新题 | 20 个本季话题，中英对照，每个话题附答题思路；标出大陆新题、9 月中旬以后新增的话题和最近两周高频 |
| Part 2 题卡 | 45 张卡，完整 You should say 提纲、串题建议，能套原作者答案的都链过去了 |
| Part 3 追问 | 255 道，按 Part 2 题卡分组 |
| 串题 | 12 组故事，每组能讲哪几张卡 |
| 计时练习 | Part 2 准备 1 分钟 + 陈述 2 分钟 + 几道 Part 3，到时间有提示音，可以录音回放；也能练 Part 1 或只计时 |
| 写作模板 | 小作文 7 种（折线、柱状、饼图、表格、混合、地图、流程图），大作文 6 种（同意与否、双边讨论、利弊、积极消极、原因+解决、双问题），每种都附 9–10 月真题 |
| 近期真题 | 2026 年 9 月 1 日到 10 月 4 日考生回忆的 36 道大作文、29 道小作文，按题型分好 |
| 原作者笔记 | 44 篇做题技巧和口语素材 |

另外有全站搜索、深浅色、“练过”标记和考试倒计时。标记和日期只存在浏览器本地。

## 原作者笔记收了什么、没收什么

来自 [flamingoTOM/lxy_ILETS](https://github.com/flamingoTOM/lxy_ILETS)（作者 @小玉你待在家里），放在 `原作者笔记/`，正文没改。

- 收录：口语 P1/P2/P3 素材，作文做题技巧（通识积累、地图、流程图、Agree or disagree、Discuss both views、Positive & Negative、AI 批改提示词）
- 没收录：他听阅真题的错题和错因（`1-做题记录/`，含同义词替换表）、自己写的作文和批改（`作文/做题记录/`）、自批改表格、讲义 PDF、合并稿，以及每篇顶部的复习打卡表

## 更新内容

改 `data/` 里的 JSON，或者 `笔记/`、`原作者笔记/` 下的 Markdown，然后：

```bash
npm install          # 第一次需要，装 Markdown 解析库
npm run build        # 重新生成 site/index.html 和 笔记/ 里的口语、真题文件
npm run publish      # 生成 → rsync 到服务器 /var/www/ielts → git push（Pages 镜像随之更新）
```

服务器上的 nginx 配置在 `/etc/nginx/sites-available/ielts`，HTTPS 证书由 certbot 自动续期。

`笔记/口语/` 下三份新题文件和 `笔记/作文/近期真题_2026年9-10月.md` 是生成的，直接改会被覆盖，要改 JSON。

原作者仓库更新后，克隆到本地再运行 `npm run import-author -- /path/to/lxy_ILETS` 重新导入。

## 注意

- 题目都是考生回忆整理的，不是雅思官方发布，各家对“新题”的标注也不一致，所以每道题都写了来源。来源清单在网页的“来源与说明”和两个 JSON 文件里。
- 大陆考区和海外考区题库不完全相同，海外专属题放在页面最后。
- 写作模板是通用结构和表达，示例段落除注明的真题外都是自拟的。

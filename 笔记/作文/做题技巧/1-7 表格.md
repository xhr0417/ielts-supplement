# 1-7 表格（Table）

## 题型识别

由行和列组成的数据表，常见的是多个类别（国家、年份、性别、职业等）在多个指标上的数据对比。

## 段落结构

| 段落 | 要做的事 | 句数建议 |
|---|---|---|
| 开头 | 改写题目，说明表格内容和范围 | 1–2 句 |
| 概述 | 写最高、最低和主要趋势，不写具体数字 | 2–3 句 |
| 细节 1 | 第一组类别的关键数据 | 4–5 句 |
| 细节 2 | 第二组类别的关键数据，并与第一组对比 | 4–5 句 |

## 开头模板

| 英文 | 中文 |
|---|---|
| The table compares / presents / illustrates … across …. | 表格比较 / 呈现了……在……方面的数据。 |
| The table provides information on … in … from … to …. | 表格提供了……在……到……期间的信息。 |

## 概述模板

| 英文 | 中文 |
|---|---|
| Overall, … recorded the highest figure for …, whereas … had the lowest. | 总体来看，……的数值最高，而……的数值最低。 |
| The most noticeable feature is that …. | 最明显的特征是…… |

## 数据句型

| 英文 | 中文 |
|---|---|
| The highest figure was recorded for … (at …). | ……的数值最高，为…… |
| … had the lowest figure, at …. | ……的数值最低，为…… |
| … was much higher / lower than …. | ……远高于 / 低于…… |
| The difference between A and B was …. | A 和 B 之间的差距为…… |
| In terms of …, … was …. | 就……而言，…… |
| By contrast, … / Whereas, … | 相比之下…… |
| A total of … | 总计…… |

## 示例（自拟数据）

Overall, the table shows that the highest number of weekly working hours was recorded in Country A, whereas Country C had the lowest figure.
**译**：总体来看，表格显示 A 国的每周工作时长最长，而 C 国最短。

## 注意

- 不要把所有数字都搬进文章，挑最高、最低、最大差异和最有代表性的 2–3 组。
- 注意表格里的 total（总计、合计）行，不要误当成某一个类别。
- 单位（%、million、per cent 等）要统一，并读清楚表头的单位。
